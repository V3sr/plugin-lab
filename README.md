## Initial recommendation

Validate **GuildBrief**, a focused community event and executive-handoff assistant, with three willing small teams. It separates confirmed decisions, proposals, unresolved questions and assigned responsibilities, with links to the source messages. Narrow workflow value and independently checked access are the hypotheses; generic Discord connectivity is already available elsewhere.

Public-store eligibility is an early dependency. OpenAI's current policy restricts unofficial third-party connectors, and adding summaries does not establish an exception. If eligibility or Discord access is blocked, test an original, upload-first **learning-page QA engine** before investing in public-store packaging.

## Working principles

- Evidence before novelty claims; links and access dates accompany platform facts.
- Authorize before retrieval; fail closed when a user's current access cannot be verified.
- Pilot with consent; keep private conversations, tokens and employer assets out of this repository.
- Measure recurring task completion and retained humans, not server membership or installs alone.
- Make real, dated commits at meaningful milestones. No fabricated users, backdated work or invented impact.

## Repository scope

This first version intentionally contains plans and research. Implementation should begin after the validation gates in the backlog. Future source, evaluations and releases belong in the chosen product package, while research alternatives remain here.

No Discord or OpenAI endorsement is claimed. GuildBrief is a working name; availability and trademark checks are pending.
