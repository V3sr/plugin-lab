## Working principles

- Link evidence and distinguish facts from proposed scores, estimates and targets.
- Validate a recurring task and an authorized data route before implementing.
- Keep private data, credentials and employer assets out of the repository.
- Measure useful repeat tasks and retained users rather than raw reach.
- Keep dated, meaningful commits and honest portfolio claims.
