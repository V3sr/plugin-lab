## Selection criteria

Prefer a task people recently performed and expect to repeat. Check whether a plugin is a useful interface for the task, whether original functionality adds value, and whether setup requirements are acceptable. Compare existing alternatives and obtain an authorized data route. Recheck public-directory eligibility for the exact chosen product.

A usable prototype, accurate failure handling, reproducible installation and measured repeat use will provide stronger resume evidence than a provider name alone.
